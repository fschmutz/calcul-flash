# Security

This is a static GitHub Pages app. There is no server and no account.

Nothing is uploaded. Name, age, language, and high scores stay in `localStorage` on this device. If you find a way the page exfiltrates player data, open a private [security advisory](https://github.com/fschmutz/calcul-flash/security/advisories/new) or an issue if that form is unavailable.

Do not report “the service worker cached an old build” here — that is [Troubleshooting](https://github.com/fschmutz/calcul-flash/wiki/Troubleshooting).
